# 合规审核体验验收 · 2026-10-26

本轮修复合规用户、原件预览、KYC 审核及验证器申诉的状态与目标隔离，保留现有敏感操作审批。

- 用户、风险标签、AML Case、验证器申诉分别处理读取结果；一处失败不掩盖其余数据，用户列表未就绪时统计显示不可用。
- 统计明确仅覆盖当前页用户；长用户 ID 保持精确并使用适合阅读的字号。
- 切换用户立即清空旧资料和可写表单，取消旧详情和原件请求；响应中的用户、KYC、材料和风险记录必须属于当前用户。
- KYC 级别与后端一致，包含 STANDARD / ENHANCED；手工审核默认服务商为 SELF。
- 审核确认列出用户、级别、状态、原因和有效期；写入期间锁定页面操作，保留原有审批单和请求体绑定。异常结果清空旧列表与可写详情，须重新查询核对。
- 申诉批准仅在打开同一用户的已通过 KYC 且有原件时提供；说明长度按后端要求为 8–500 字。确认列出申诉、用户和解除旧验证器/冻结提现 24 小时的影响。
- 原件使用居中的原生模态窗口，显示当前用户；支持焦点恢复、Escape、背景滚动锁定、取消读取及对象 URL 释放。390/320px 下检查长文件名、按钮换行和预览内容无溢出。

复现：

```sh
npm run lint
npm test
npm run build
npm run dev -- --host 127.0.0.1 --port 5184
QA_PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs QA_CHROMIUM=/path/to/chromium QA_OUTPUT=/path/to/evidence node scripts/compliance-experience-qa.mjs
```

浏览器操作包括列表局部故障、用户连续切换、取消慢响应、错误所属用户、合成原件查看/取消、审核取消、审批失败恢复、短原因拦截和申诉决定成功刷新。1440×1000、390×844、320×844、亮暗主题截图及 60 秒观察见 [机器记录](compliance-experience-20261026.json)。

全部 HTTP 与写请求均为明确的隔离测试数据，未执行真实审批、认证决定、验证器解除或资金动作。未测真实原件存储/PDF 查看器、真实双人审批、身份比对、风险标签/AML 写入和完整线上权限矩阵；60 秒观察不构成生产稳定性保证。全后台与用户端的整体目标仍在继续。
