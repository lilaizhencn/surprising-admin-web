# 公告管理体验验收 · 2026-10-26

本轮明确保存、发布与撤回的边界，保留后台原有权限、版本控制和敏感操作审批。

- 查询取消旧请求并延迟搜索，加载/失败不显示假零总数或“暂无公告”；列表复用共享表格与窄屏卡片。
- 公告、版本、审计和管理员 ID 均按精确十进制字符串处理；响应校验状态、范围、分页和记录归属。
- 新建与编辑必须先保存，再发布已保存版本；取消发布原因或确认均不产生保存、更新或发布写入。发布需完成中英文，并确认标题、编号、版本、投放范围和时间。
- 保存已发布内容明确提示会直接更新投放并清除已读记录；未修改时间字段时保留服务器原始秒及小数精度。
- 写入期间锁定字段和导航，失败阻断旧版本继续写入并提供重新载入；不会自动重试创建或敏感写入。未保存内容关闭、切换编辑对象和侧栏离开前可取消。
- 撤回保留原因、目标确认及审批；已撤回公告必须显式保存为草稿才能重新发布。审计查询切换、关闭与页面卸载会取消旧请求。
- 中英文可分别预览；编辑栏、长 ID、按钮与预览正文覆盖桌面/390/320px、亮暗主题。
