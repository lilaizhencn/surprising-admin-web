# 客服工单体验验收

日期：2026-10-27。本记录覆盖客服工作台，本批通过不代表全站任务完成。

## 结果与契约

工作台按已查询的用户 ID 展示身份/合规摘要、工单和备注时间线。后台现有摘要只包含 `generatedAt/user/compliance`，本页因此移除了没有来源的资产、订单和产品线空表；缺字段不能变成零风险或空列表。查询用户、工单、备注均校验目标和响应边界，保留 int64 字符串身份。

工单支持中文状态和优先级、状态筛选、原生游标分页和窄屏卡片。切换用户或工单取消旧读取并清除旧内容；返回列表会寻找当前尺寸下可见的原记录按钮恢复焦点。新建、内部备注和状态变更保留原权限与接口，提交中锁定操作并校验回执目标。状态确认含用户、工单、原状态、新状态和原因。明确的业务拒绝保留原因；未知结果阻止重复提交，先重新查询并核对工单/时间线。

核对的后端文件：`AdminSupportController`、`SupportRequestBinding`、`SupportModels`、`SupportTicketService`，以及原生分页绑定。标题最多 160 字，备注/原因最多 2000 字，分类代码遵守原字符限制；工单每页不超过 100。没有新建后端接口，也没有扩大 SUPPORT 权限。CodeGraph 工具本轮不可用，按已知文件核对源代码。
